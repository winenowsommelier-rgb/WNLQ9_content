📊 System Overview

The WNLQ9 Blog Workflow Dashboard integrates multiple data sources and APIs to automate content brief creation, Notion tracking, and status notifications.

Google Search Console | Notion Database | Slack Webhooks
(Keywords, CTR) | (Brief storage) | (Notifications)

Key Principles

✅ Data-driven: Briefs generated from GA trends + GSC keywords

✅ Cached: GA/GSC data cached 6 hours, refresh on demand

✅ Write-enabled: App creates Notion rows, posts to Slack

✅ Expandable: API structure ready for Magento + GA real-time

📈 Data Sources

1. Google Analytics 4 (GA4)

Aspect Details Status
Purpose Identify trending wine/spirits topics, search volume Manual Import
Data Extracted Top 50 pages by views (last 30 days), device breakdown, traffic source To Do
Update Frequency Weekly (or on-demand refresh in dashboard) Scheduled
Format CSV export → upload to app Pending
API Integration Google Analytics 4 API (OAuth 2.0) Future (Week 3)

How to Export GA4 Data

Step 1: Go to GA4 dashboard → Reporting → Engagement → Pages and screens

Step 2: Filter: Last 30 days, Wine-Now and LIQ9 properties separate

Step 3: Export as CSV (top 50 pages)

Step 4: Upload CSV to dashboard → Settings → Import GA Data

Property IDs needed: Wine-Now (TBD) + LIQ9 (TBD)

2. Google Search Console (GSC)

Aspect Details Status
Purpose SEO keywords, search volume, CTR, keyword clustering Manual Import
Data Extracted Top 100 keywords, impressions, clicks, position, CTR To Do
Update Frequency Weekly (or on-demand) Scheduled
Format CSV export → upload to app Pending
API Integration GSC API → Supabase sync (read live by dashboard) Live via Supabase

How to Export GSC Data

Step 1: Go to Google Search Console → Performance

Step 2: Filter: Last 90 days, Wine-Now and LIQ9 properties separate

Step 3: Select all rows → Export as CSV

Step 4: Upload CSV to dashboard → Settings → Import GSC Data

Domains needed: wine-now.com + liq9.com (GSC properties)

3. Supermetrics

DISCONNECTED — not used. GA4 + GSC data is synced directly into Supabase (project WNLQ9 SEO Automation) and read live by the dashboard. No third-party connector sits in the data path.

🔑 APIs & Authentication

1. Google APIs (GA4 + GSC)

Service Method Credentials Status
Google Analytics 4 API OAuth 2.0 + Service Account → Supabase sync JSON key file Live via Supabase
Google Search Console API OAuth 2.0 + Service Account → Supabase sync JSON key file (same as GA4) Live via Supabase

Setup (Deferred to Week 3)

Step 1: Create Google Cloud Project

Step 2: Enable Google Analytics 4 API + Google Search Console API

Step 3: Create Service Account → Download JSON key

Step 4: Add service account email to GA4 + GSC properties (read-only)

Step 5: Add JSON key to .env.local: GOOGLE_SERVICE_ACCOUNT_KEY

2. Notion API

Aspect Details Status
Method OAuth 2.0 + Bearer Token Ready Week 1
Capability Create rows, read rows, update status Read + Write
Database ID 786d080f8da24a1eb84e161f4e19d56d ✓ Known

Setup (Week 1)

Step 1: Go to notion.so/my-integrations

Step 2: Create new integration "WNLQ9 Dashboard"

Step 3: Copy Bearer token

Step 4: Share database (786d080f8da24a1eb84e161f4e19d56d) with integration

Step 5: Add to .env.local: NOTION_API_TOKEN=secret_xxx

3. Slack API

Aspect Details Status
Method Incoming Webhooks Ready Week 1
Capability Post notifications (no auth needed from app) Write-only
Channels #content-workflow (briefs, HTML, publish updates) To Configure

Setup (Week 1)

Step 1: Go to Slack workspace → Settings → Apps & Integrations

Step 2: Search "Incoming Webhooks" → Install

Step 3: Create webhook for #content-workflow channel

Step 4: Copy webhook URL

Step 5: Add to .env.local: SLACK_WEBHOOK_URL=https://hooks.slack.com/...

🔄 Connection Flows

Data Import Flow (Week 1-2: Manual)

Google Analytics 4 Dashboard
Export: Top 50 pages (last 30 days)
↓
Download as CSV
↓
Dashboard → Settings → "Import GA Data"
↓
Cached in memory (6-hour TTL)
↓
Used in Brief Generator to suggest topics

Brief Creation Flow

User selects: Date + Brand (Wine-Now/LIQ9)
↓
Dashboard pulls: GA trends + GSC keywords
↓
Generate 3 brief options (with KEY/TENSION/STORY)
↓
User picks best option
↓
Brief Editor (final polish)
↓
"Save to Notion" → Notion row created
↓
Slack notification: "Brief ready"

Publication Flow

Notion Database (Brief Ready)
↓
wnlq9-blog-writer skill (HTML generation)
↓
HTML file saved to Google Drive
↓
Dashboard updated: Publication Tracker
↓
Slack notification: "HTML generated"
↓
Paste to Magento CMS
↓
Update Notion: "Published" + live URL
↓
Slack notification: "LIVE"

📋 Notion Database Schema

Database ID: 786d080f8da24a1eb84e161f4e19d56d

Current status: Created + populated (June 1-2 content)

Field Name Type Purpose Auto-Filled
Publish Date Date When content goes live No (user input)
Brand Select Wine-Now / LIQ9 No (user input)
Topic Text (Title) Brief headline No (user input)
KEY Text Main takeaway No (user input)
TENSION Text What readers wonder No (user input)
STORY Text Narrative arc No (user input)
SEO Keyword Text Primary keyword from GSC No (user input)
Status Select Brief Ready / In Progress / Review / Done / Published Auto: "Brief Ready"
HTML File URL Link to GDrive HTML No (manual update)
Magento URL URL Live URL on wine-now.com or liq9.com No (manual update)
GA Views Number Page views after publish No (manual update)
Brief ID Text App-generated ID for linking Yes (app)
Created Created time When row created Yes (Notion)

API Integration Points

Write (App → Notion): Brief Editor "Save to Notion" button creates new row with all fields populated

Read (Notion → App): Publication Tracker reads all rows to show status grid

Update (Notion ← Manual): User updates HTML File, Magento URL, GA Views manually

Location: Project root → .env.local (DO NOT commit to git)

# Notion API NOTION_API_TOKEN=secret_xyz... NOTION_DATABASE_ID=786d080f8da24a1eb84e161f4e19d56d # Slack Webhook SLACK_WEBHOOK_URL=https://hooks.slack.com/services/T00/B00/XXXX # App Config NEXT_PUBLIC_BRANDS=wine-now,liq9 NEXT_PUBLIC_APP_URL=http://localhost:3000 NODE_ENV=development

Week 3 Setup (Google APIs)

# Google Cloud GOOGLE_SERVICE_ACCOUNT_KEY={...json key file contents...} GOOGLE_GA4_PROPERTY_ID=123456789 GOOGLE_GSC_DOMAIN_WINE_NOW=wine-now.com GOOGLE_GSC_DOMAIN_LIQ9=liq9.com # Data caching DATA_CACHE_TTL_HOURS=6

Security Notes

✅ Never commit .env.local to git

✅ Service account keys should be treated as secrets

✅ Add .env.local to .gitignore

✅ Share .env.example with placeholders (no real values)
