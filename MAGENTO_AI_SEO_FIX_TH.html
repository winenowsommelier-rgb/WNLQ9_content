1 แก้ Technical SEO ใน Magento

1.1 ตั้งค่า Canonical Tag ให้ครบ ⭐

ปัญหา: Magento สร้าง URL ได้หลายแบบสำหรับสินค้าเดียวกัน เช่น /robert-mondavi.html, /red-wine/robert-mondavi.html, /robert-mondavi.html?color=red → Google มองว่าเป็นเนื้อหาซ้ำ อันดับตก

วิธีแก้ (Magento Admin):

Stores → Configuration → Catalog → Catalog → Search Engine Optimization
- Use Canonical Link Meta Tag for Categories = Yes
- Use Canonical Link Meta Tag for Products = Yes

ตรวจสอบใน HTML ว่าได้:

<link rel="canonical" href="https://th.wine-now.com/robert-mondavi-cabernet.html" />

1.2 ควบคุม Layered Navigation (Filter) ⭐ สำคัญมาก

ปัญหา: หน้า filter เช่น ?price=500-1000&color=red สร้าง URL ได้เป็นพันๆ แบบ Google crawl จนหมด budget แล้วไม่เหลือมา crawl หน้าสินค้าจริง

วิธีแก้ที่ 1 — robots.txt (บล็อก parameter):

# Block layered navigation parameters
Disallow: /*?price=
Disallow: /*?color=
Disallow: /*?size=
Disallow: /*?material=
Disallow: /*?*filter
Disallow: /*?p=
Disallow: /*?product_list_order=
Disallow: /*?product_list_dir=
Disallow: /*?product_list_limit=

วิธีแก้ที่ 2 — เพิ่ม noindex, follow ที่หน้า filter:

ถ้าใช้ extension Amasty Improved Layered Navigation หรือ Mirasvit ให้เปิด: Add nofollow to filter links = Yes, Add noindex,follow robots meta = Yes, Use canonical to main category = Yes

// ถ้าไม่มี extension: ใน Block/Plugin
if ($this->hasFilterParams()) {
    $this->pageConfig->setRobots('NOINDEX,FOLLOW');
    // set canonical กลับไปหน้า category หลัก
}

1.4 XML Sitemap ที่ถูกต้อง

Stores → Configuration → Catalog → XML Sitemap
- Products: Frequency = daily, Priority = 1.0
- Add product images to sitemap = Yes  ⭐ (สำคัญ! Google Images + AI)
- Generation: Enabled = Yes, Frequency = Daily, Start Time = ตี 3
  • สินค้า out-of-stock / disabled ต้อง ไม่ อยู่ใน sitemap
  • ทุก URL ต้องตอบ HTTP 200 (ไม่ใช่ 301/404)
  • Submit ทั้ง 2 sitemap ใน Google Search Console

1.5 Title & Meta ไม่ให้ซ้ำ

ปัญหา: Magento ใช้ template เดียว title ซ้ำกันหมด → CTR ต่ำ (4.26%)

Stores → Configuration → Catalog → Catalog → Product Fields Auto-Generation
- Mask for Meta Title: {{name}} ราคา | Wine Now & LIQ9
- Mask for Meta Description: ซื้อ {{name}} ของแท้ ราคาดี จัดส่งไว {{short_description}}
💡
หน้า traffic สูง (homepage, expensive wine, champagne, robert mondavi) ให้เขียน title/meta เองทุกหน้า — ดูสูตรใน QUICK_WINS_THIS_WEEK.md

1.6 Pagination & 1.7 URL สะอาด

Stores → Configuration → General → Web → Search Engine Optimization
- Use Web Server Rewrites = Yes   (ตัด index.php)

Catalog → Search Engine Optimization
- Use Categories Path for Product URLs = No  ⭐ (ป้องกัน URL ซ้ำ)
- Create Permanent Redirect if URL Key Changed = Yes
⚠️
ถ้าเปลี่ยน URL suffix ต้องทำ 301 redirect ทุก URL เก่า ไม่งั้นอันดับหายหมด

2 ทำให้ AI เข้าถึงข้อมูลได้ดี (GEO)

GEO (Generative Engine Optimization) = การทำให้ AI search ดึงข้อมูลและ อ้างอิงเว็บเรา เมื่อผู้ใช้ถามเกี่ยวกับไวน์ เป็น traffic ช่องทางใหม่ที่กำลังโตเร็วมาก

2.1 สร้างไฟล์ llms.txt ⭐

ไฟล์มาตรฐานใหม่ (เหมือน robots.txt แต่สำหรับ AI) บอก AI ว่าเว็บเรามีอะไร อ่านตรงไหน — สร้างที่ https://th.wine-now.com/llms.txt

# Wine Now (th.wine-now.com)

> ร้านไวน์และเครื่องดื่มแอลกอฮอล์ออนไลน์ชั้นนำในไทย จำหน่ายไวน์แดง
> ไวน์ขาว แชมเปญ สปาร์กลิงไวน์ และไวน์ราคาพิเศษ จัดส่งทั่วไทย

## สินค้าหลัก (Product Categories)
- [ไวน์แดง](https://th.wine-now.com/red-wine): Bordeaux, Napa, Tuscany
- [แชมเปญ](https://th.wine-now.com/champagne): Moët, Dom Pérignon
- [ไวน์ราคาพิเศษ](https://th.wine-now.com/expensive-wine): ฿500-฿100,000+

## คู่มือและความรู้
- [วิธีเลือกไวน์](https://th.wine-now.com/wine-guide)
- [การจับคู่ไวน์กับอาหาร](https://th.wine-now.com/wine-pairing)

## ข้อมูลร้าน
- จัดส่งฟรีเมื่อสั่ง ฿1,000+ / สินค้าของแท้ 100% / มี sommelier แนะนำ

ทำแบบเดียวกันสำหรับ th.liq9.com/llms.txt — ใน Magento สร้างเป็น static file ใน pub/ หรือ CMS page + URL rewrite

2.3 เนื้อหาต้องเป็น Server-Side Rendered (SSR) ⭐

ปัญหา: AI crawler ส่วนใหญ่ ไม่ run JavaScript ถ้าราคา/รายละเอียดโหลดด้วย JS/AJAX → AI มองไม่เห็น

ทดสอบ: ปิด JavaScript ใน browser แล้วเปิดหน้าสินค้า — เห็นราคา = ผ่าน, หน้าว่าง = ต้องแก้

  • Magento (Luma theme) เป็น SSR อยู่แล้ว ✅ — แต่ถ้าใช้ PWA/Headless (Venia) ต้องทำ SSR/prerender เพิ่ม
  • ราคาและ stock ต้อง render ใน HTML ตั้งแต่แรก ไม่ใช่โหลดทีหลังด้วย AJAX

2.4 โครงสร้างเนื้อหาที่ AI ชอบ (Citability)

<h2>แชมเปญต่างจากสปาร์กลิงไวน์อย่างไร?</h2>
<p>แชมเปญคือสปาร์กลิงไวน์ที่ผลิตเฉพาะในแคว้นช็องปาญ ฝรั่งเศส
ด้วยกรรมวิธี méthode traditionnelle ส่วนสปาร์กลิงไวน์ทั่วไป
ผลิตที่ไหนก็ได้ ราคาเริ่มต้น ฿400</p>
  1. ใช้ heading เป็นคำถาม (H2/H3) — ตรงกับที่คนถาม AI
  2. ตอบใน 2-3 ประโยคแรกทันที (ไม่อ้อมค้อม)
  3. ใส่ตัวเลข/ข้อเท็จจริงชัดเจน (ราคา, ปี, %)
  4. ใช้ bullet list และ table สำหรับเปรียบเทียบ
  5. มี FAQ section ในทุกหน้าสำคัญ

2.5 E-E-A-T Signals

  • ใส่ชื่อ sommelier/ผู้เชี่ยวชาญ ที่เขียน tasting notes (พร้อม credential เช่น WSET, Certified Sommelier)
  • หน้า About บอกประสบการณ์ร้าน
  • ใส่วันที่อัปเดต (dateModified ใน schema)
  • มีรีวิวจริงจากลูกค้า (พร้อม Review schema)

3 Schema Markup (JSON-LD)

🔥
นี่คือสิ่งที่ให้ผลเร็วและแรงที่สุด ทั้งสำหรับ rich results ใน Google และให้ AI เข้าใจสินค้า

3.1 Product Schema (ทุกหน้าสินค้า) ⭐⭐⭐

<script type="application/ld+json">
{
  "@context": "https://schema.org/",
  "@type": "Product",
  "name": "Robert Mondavi Cabernet Sauvignon 2019 750ml",
  "image": ["https://th.wine-now.com/media/catalog/product/r/m/robert.jpg"],
  "description": "ไวน์แดง Cabernet Sauvignon จาก Napa Valley รสนุ่มนวล กลมกล่อม",
  "brand": { "@type": "Brand", "name": "Robert Mondavi" },
  "sku": "RM-CAB-2019",
  "offers": {
    "@type": "Offer",
    "url": "https://th.wine-now.com/robert-mondavi-cabernet.html",
    "priceCurrency": "THB",
    "price": "850",
    "priceValidUntil": "2026-12-31",
    "availability": "https://schema.org/InStock",
    "itemCondition": "https://schema.org/NewCondition"
  },
  "aggregateRating": {
    "@type": "AggregateRating",
    "ratingValue": "4.7",
    "reviewCount": "24"
  }
}
</script>

วิธีทำใน Magento:

  • แนะนำ: ติดตั้ง extension Magefan Rich Snippets, Amasty SEO Toolkit, หรือ MageWorx SEO Suite — generate อัตโนมัติทุกสินค้า
  • หรือ: Dev เขียน template ใน view/frontend/templates/product/view/ ดึงค่าจริงจาก product object
⚠️
Magento native มี structured data แค่บางส่วน (มักไม่ครบ/ไม่ valid) — แนะนำใช้ extension ดีกว่าเขียนเอง

3.2 FAQPage Schema (category + บทความ) ⭐⭐

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [{
    "@type": "Question",
    "name": "Prosecco คืออะไร?",
    "acceptedAnswer": {
      "@type": "Answer",
      "text": "Prosecco คือสปาร์กลิงไวน์อิตาลีจากองุ่น Glera รสเบาและหวานกว่าแชมเปญ ราคาเริ่ม ฿400"
    }
  }]
}
</script>
💡
FAQ schema ช่วย 2 อย่าง: rich result ใน Google + AI ดึงไปตอบใน AI Overviews/ChatGPT — ตอบโจทย์ keyword "prosecco คือ", "most expensive wine" ที่ impression สูงแต่ click ต่ำ

3.3 BreadcrumbList + 3.4 Organization Schema

เพิ่ม BreadcrumbList ทุกหน้า และ Organization/OnlineStore schema ที่หน้าแรก (ใส่ logo, sameAs social, contactPoint)

3.5 ตรวจสอบ Schema

ทดสอบทุกหน้าที่ validator.schema.org และ search.google.com/test/rich-results

4 Core Web Vitals / ความเร็ว

Magento หนักโดยธรรมชาติ ถ้าไม่ optimize จะช้ามาก ทำให้อันดับตกและ AI crawler timeout

4.1 เปิด Full Page Cache + Varnish ⭐

Stores → Configuration → Advanced → System → Full Page Cache
- Caching Application = Varnish Cache (แนะนำ)

ตั้ง Varnish บน server (ไม่ใช่ built-in cache) — ลด TTFB จากวินาทีเหลือ < 200ms

4.2 Production Mode + รวม/ย่อ JS/CSS

php bin/magento deploy:mode:set production

Stores → Configuration → Advanced → Developer
- Merge + Minify JavaScript = Yes
- Merge + Minify CSS = Yes
- Minify Html = Yes

4.3 Optimize รูปภาพ (ร้านไวน์มีรูปขวดเยอะ)

  • แปลงรูปเป็น WebP (ลดขนาด 25-35%) — ใช้ Mageplaza WebP หรือ CDN
  • ใส่ loading="lazy" กับรูปใต้ fold
  • ใส่ width/height ป้องกัน CLS
  • ใส่ alt text ทุกรูป (SEO + AI + accessibility)

4.4-4.5 CDN & Indexing

# Indexer เป็น schedule (cron) ไม่ใช่ on save
php bin/magento indexer:set-mode schedule

ใช้ CDN (Cloudflare/Fastly) สำหรับ static + media files

4.6 เป้าหมาย Core Web Vitals

Metricเป้าหมายความหมาย
LCP< 2.5sโหลดเนื้อหาหลักเร็ว
INP< 200msตอบสนองการคลิกเร็ว
CLS< 0.1หน้าไม่กระตุก
TTFB< 200msserver ตอบเร็ว (Varnish ช่วย)

ทดสอบที่ pagespeed.web.dev (ใส่ URL ทั้ง 2 เว็บ)
