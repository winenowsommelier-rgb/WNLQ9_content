## 2️⃣ Process Overview & Definition

**Name:** Premium Content Replacement Workflow
**Category:** Content Strategy & Production
**Type:** Replacement + Upgrade (not enhancement)
**Scope:** Multi-topic, multi-site, data-driven
**Output:** Production-ready content briefs in a standardized template

**Core phases (≈4.5 hrs / 1 focused session):**
1. **Discovery & Alignment** (30 min) — confirm replace intent, identify old items, confirm personas, define metrics
2. **Market Research** (45 min) — web search trends, extract growth rates/producers/data, compile specific stories
3. **Topic Ideation & Selection** (30 min) — organize findings, select balanced set, rationale + keywords
4. **Brief Creation** (60 min) — KEY/TENSION/STORY, Image Strategy, Controversy, Production Notes, FAQ, Persona
5. **Research Integration** (45 min) — weave producer names, exact data, auction records, regional detail (3–5 per brief)
6. **Database Replacement** (30 min) — fetch schema, create pages, populate fields, mapping log, Status="Not started"
7. **Handoff & Documentation** (20 min) — summarize, document remaining steps, write this memory doc

## 9️⃣ Open-Source Process Comparison

| Framework | Strength | Limitation | Our edge |
|---|---|---|---|
| Content Audit + Replacement (agencies) | Structured, audit-first | Slower, doc-heavy | Research-first, faster |
| Pillar + Cluster (HubSpot/Semrush) | SEO linking | Built for new content | Works for replacement (keeps traffic) |
| Agile Content Sprint (SaaS) | Parallel, cross-functional | Needs teams | Solo-friendly, single session |
| Content Operations (Contently/Skyword) | Enterprise governance | Heavyweight | Lightweight, manual gates |

**Recommended hybrid:** add **Pillar-Cluster** structure in Phase 3 — designate pillars (1500–2000 words) + 2–3 cluster posts (500–800 words) each, with an internal-link plan.
*Example (Wine-Now Item 1 Pillar):* clusters = "Burgundy Allocation: why 41.3%", "Younger Vintages Trending", "Liv-ex Index Tracking."
