01 · ขั้นตอนการทำงาน (The loop)

📋 อ่านแผนใน Notion→ ✍️ เขียนบทความ ไทยเต็มรูปแบบ→ 🍷 ใส่การ์ด SKU จริง→ 🔎 ไม่มโนตัวเลข (verify-list)→ 📄 รวม CSS เป็นไฟล์เดียว→ ☁️ อัป Google Drive→ ✅ Notion = "Brief Ready"

Notion board “2026 JUN — WNLQ9 — Content Production” คือแหล่งความจริงว่า จะทำอะไรและสถานะไหน; ไฟล์ใน repo (pipeline/public/content/) คือแหล่งความจริงของตัวบทความ; โฟลเดอร์ Drive “WNLQ9 Blog Html center” คือปลายทางส่งมอบ (HTML รวม CSS ในตัว)

02 · กฎทอง (ห้ามข้าม)

1 · ไทยล้วน เต็มรูปแบบ

เขียนเป็นบทความพร้อมใช้จริงที่ความลึกระดับ “Whisky 101 v2” ไม่ใช่ brief และต้องถึง Word Target

2 · ไม่มโนข้อมูล

ห้ามแต่งภาษี ราคา คะแนนนักวิจารณ์ อันดับขายดี ABV/PPM — เขียนเลี่ยง + ใส่หมายเหตุให้ตรวจสอบ และทำ verify-list

3 · SKU จริงทุกการ์ด

data-sku + ชิป SKU: ที่มองเห็น ใช้เฉพาะ SKU ในสต็อกจากฟีด ไม่มีของ = 0 การ์ด แล้วส่งไป LINE

4 · คอมพลายแอนซ์

ราคาเป็นค่าประมาณ ~฿ + “สอบถามราคา/สั่งซื้อทาง LINE”, ฟุตเตอร์ ดื่มอย่างมีความรับผิดชอบ · 20+, มี byline E-E-A-T

5 · มาตรฐาน HTML

หน้า standalone, article.css ร่วม, ฟอนต์ Sarabun, canonical, OG+Twitter, JSON-LD 3 บล็อก (headline = H1), รูปถือ aspect-ratio 16/9 กัน CLS

6 · ส่งมอบ & สถานะ

อัป HTML รวม CSS เข้า Drive → ใส่ลิงก์ในช่อง Drive file URL → ตั้ง Status = “Brief Ready” (ไม่ใช่ Done)

หมายเหตุประสิทธิภาพ: บทความเป็น static + ไม่มี JS + CSS inline → Core Web Vitals ดีเยี่ยม รักษาไว้ด้วยการสำรองสัดส่วนรูปภาพและไม่เพิ่มสคริปต์ที่บล็อกการเรนเดอร์

04 · เครื่องมือ & โครงสร้าง

  • Notion — บอร์ดแผนงาน + สถานะ (Status, Drive file URL)
  • Repo — บทความที่ pipeline/public/content/*.html + สไตล์ร่วม assets/article.css
  • Google Drive — โฟลเดอร์ส่งมอบ HTML รวม CSS (MCP เขียนทับ/ลบไม่ได้ → รีอัปต้องเคลียร์โฟลเดอร์ก่อน)
  • Vercel — โปรเจกต์ seodashboard (Root Directory pipeline/) เสิร์ฟแดชบอร์ด + บทความ
  • Supabase — sync แผนคอนเทนต์ + เลือกสินค้า (content_plan, plan_with_picks)
