### 2B. AEO (win the answer) — **NEW this month, applies to every piece**
Answer engines lift *passages*, not pages. The checklist that goes into every July brief + HTML:

1. **Answer-first blocks.** Each H2 opens with a **40–60 word self-contained answer** to the question in the
   heading — before context, story, or product. This is the unit an AI Overview / snippet extracts.
2. **Definitional anchor.** Within the first 100 words: *"<X> คือ…"* — one clean sentence that defines the
   entity. (e.g., *"คาวา (Cava) คือ ไวน์สปาร์กลิงจากสเปนที่ผลิตด้วยกรรมวิธีเดียวกับแชมเปญ…"*)
3. **Question-shaped headings** matching real Thai queries (mine GSC + People-Also-Ask): *"…คืออะไร", "…ยี่ห้อไหนดี",
   "…ราคาเท่าไหร่", "…กับ…ต่างกันอย่างไร"*. These map 1:1 to how people prompt an AI.
4. **Comparison tables + tight lists.** Engines preferentially extract "X vs Y" and "best/types of X" as
   tables/lists. Every comparison or ranking gets a real table (no invented ranks/scores).
5. **Entity specificity = authority.** Name producers, regions, grapes/styles, real ABV/price-bands. Dense,
   correct entities are how an engine learns *this site knows the topic* → cites it.
6. **Verifiable facts only, dated.** Cite a source or the BI feed; add *"อัปเดต 2026"*. No fabricated tax/price/
   score/ABV. The no-fabrication rule **is** an AEO trust signal — extractable + correct = cited.
7. **Schema discipline.** Article (headline = H1) + **FAQPage that mirrors the on-page FAQ with self-contained
   answers** + HowTo where stepwise. Add `speakable` on the answer block where natural.
8. **Brand-entity building.** Consistent E-E-A-T byline (Sommelier Desk / Bartender Desk) + about/author signals
   so the *brand itself* becomes a recognized entity an engine names.
9. **Bilingual answer targeting.** Thai answer blocks on the TH/base canonical (we own Thai SERPs); EN regional
   via hreflang. Don't collapse languages.

> **AEO acceptance test for any July page:** *Could ChatGPT/Gemini answer the headline question by quoting one
> block of this page verbatim, and would it be correct?* If no → rewrite the block.

## 4. Trend & timing layer (July 2026, Thailand)
Goal #2 (in-trend) + goal #3 (market value). Two inputs: cultural trends + the Thai calendar.

### Trends to ride (lead with the ones already showing demand)
- **Low-/no-ABV & sessionable** — global shift; pairs with monsoon-season at-home drinking. WN: lighter whites/
  rosé/low-ABV sparkling; LIQ9: highball, lower-proof serves, 0% mixers.
- **Natural / orange / "clean" wine** — Enthusiast-tier curiosity; strong AEO "…คืออะไร" demand. (WN.)
- **Premiumization & gifting** — fewer-but-better; feeds the Collector + Gifter personas and the premium cluster.
- **Japanese highball / whisky-soda culture** — LIQ9 Discovery on-ramp; cheap to enter, high share-ability.
- **Agave moment (tequila/mezcal)** — sustained Enthusiast trend; LIQ9.
- **Home-bar / home-entertaining** — monsoon = indoor hosting season in TH; both brands (host/occasion).

### Thai calendar pegs (⚠️ compliance-critical)
- **Asalha Puja & Wan Khao Phansa (เข้าพรรษา / start of Buddhist Lent)** fall in **late July 2026 — verify exact
  dates before scheduling.** On these Buddhist holy days **alcohol sales are legally restricted in Thailand**.
  **Plan:** schedule **no commercial pushes / promotions / "สั่งซื้อ" campaigns on those dates**; run
  **educational / cultural / mindful-drinking** content instead (also a brand-trust + responsibility signal that
  feeds E-E-A-T). Resume commercial cadence after. *(Verify-note: confirm 2026 dates against an official source.)*
- Otherwise July is a low-festival, indoor, monsoon month → evergreen education + home-entertaining over events.
