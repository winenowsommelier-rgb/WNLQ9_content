# Wine Now Sommelier - SEO Analysis Project

This project integrates the **Claude SEO** skill for comprehensive SEO analysis and web optimization. It includes 25+ SEO specialist sub-skills covering technical SEO, content analysis, schema markup, and more.

## Available SEO Skills

The project includes the following SEO analysis tools:

- **seo** - Main SEO analysis framework
- **seo-audit** - Full site audits with prioritized action plans
- **seo-backlinks** - Backlink analysis
- **seo-cluster** - Content cluster mapping
- **seo-competitor-pages** - Competitive page analysis
- **seo-content** - Content quality analysis
- **seo-content-brief** - Content brief generation
- **seo-ecommerce** - E-commerce specific SEO
- **seo-google** - Google Search Console integration
- **seo-local** - Local SEO analysis
- **seo-technical** - Technical SEO audits
- **seo-schema** - Schema.org markup analysis
- And 13+ more specialized skills...

## Quick Start

Use Claude Code to run SEO analysis commands:

```bash
/seo audit https://example.com
/seo schema https://example.com
/seo content https://example.com
/seo technical https://example.com
```

## Setup

All required skills and agents are in the `.claude/` directory. The project includes Python dependencies in `.claude/requirements.txt`.
