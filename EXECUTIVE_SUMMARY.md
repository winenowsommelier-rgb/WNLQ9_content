## 🎯 ROOT CAUSES (Why Users Aren't Clicking)

### 1. Weak Titles & Meta Descriptions
- Generic titles don't stand out in search results
- No compelling reason for users to click YOUR link vs competitors
- Missing keywords that match search intent

**Example of Bad Title:**
```
"Wine" or "Expensive Wine"
```

**Example of Good Title:**
```
"Premium Expensive Wines | Rare Collection ฿500-฿5,000+ | Wine Now"
- Has primary keyword (expensive wines)
- Has benefit (rare, premium)
- Has price range (incentive)
- Has brand name
```

### 2. Keyword Positioning Issues
- Many keywords ranking at position 10+ (page 2)
- Position 10 = ~2% CTR
- Position 5 = ~10% CTR
- **Solution:** Move keywords to page 1 = 5X more clicks

### 3. Missing Schema Markup
- No price showing in search snippets
- No ratings/reviews visible
- No "In Stock" badge

**Current Result in Search:**
```
Robert Mondavi Wine - Wine Now
www.wine-now.com › products › robert-mondavi
Just a link and description
```

**With Schema (What Users See):**
```
Robert Mondavi Cabernet Sauvignon - Wine Now
⭐⭐⭐⭐⭐ (24 reviews)
฿850 | In Stock
Smooth, balanced California Cabernet Sauvignon...
```

**Impact:** +25-30% CTR on product pages

### 4. Irrelevant Keyword Ranking
- Ranking for "bottle stopper": 2,482 impressions, **0 clicks**
- Ranking for "glass wine": 643 impressions, **0 clicks**
- These irrelevant keywords waste impressions

**Solution:** Remove or fix these pages

### 5. Brand Over-Dependency
- 72% of clicks from branded searches ("wine now", "liq9")
- Only 28% from category searches ("champagne", "expensive wine")
- Risk: If brand awareness drops, traffic crashes
- **Solution:** Build category keyword traffic
